## Stand-Alone Reference

### Classical Pronouns
- <span style="color:#6edcb8">wú</span> / <span style="color:#a78bfa">wǒ</span> = I, me (吾/我)
- <span style="color:#a78bfa">rǔ</span> / <span style="color:#a78bfa">nǐ</span> = you (汝/你)
- <span style="color:#ff6b35">QÍ</span> = he, she, it, they (其)
- <span style="color:#b0b0b0">Zhī</span> = him, her, it (之)

### Classical Particles
- <span style="color:#a78bfa">yě</span> = (statement marker) (也)
- <span style="color:#a78bfa">yǐ</span> = (completed action) (矣)
- <span style="color:#ff6b35">ZĀI</span> = (exclamation) (哉)
- <span style="color:#ff6b35">HŪ</span> = (question particle) (乎)
- <span style="color:#b0b0b0">Zhě</span> = (nominalizer) (者)

### Common Classical Words
- <span style="color:#a78bfa">zhě</span> = (topic marker) (者)
- <span style="color:#ff6b35">FĒI</span> = is not (非)
- <span style="color:#a78bfa">yǒu</span> = have, exist (有)
- <span style="color:#6edcb8">wú</span> = not have (無)
- <span style="color:#b0b0b0">Wèi</span> = for, to be (為)

### Prior Vocabulary (Lesson 1)
- <span style="color:#ff6b35">YĪN</span> = yin, the shady principle (陰)
- <span style="color:#6edcb8">yánG</span> = yang, the bright principle (陽)
