## Practice Patterns

> **💡 Pattern:** A <span style="color:#b0b0b0">Zài</span> <span style="color:#a78bfa">nǎ</span>?
> *"Where is A?" — 在 marks location, 哪 asks "where"*

1. <span style="color:#a78bfa">nǐ</span> <span style="color:#b0b0b0">Zài</span> <span style="color:#a78bfa">nǎ</span>? — Where are you?

2. <span style="color:#ff6b35">TĀ</span> <span style="color:#b0b0b0">Zài</span> <span style="color:#a78bfa">nǎ</span>? — Where is he?

3. <span style="color:#b0b0b0">Nà</span> <span style="color:#6edcb8">réN</span> <span style="color:#b0b0b0">Zài</span> <span style="color:#a78bfa">nǎ</span>? — Where is that person?

> **💡 Pattern:** A <span style="color:#b0b0b0">Zài</span> <span style="color:#b0b0b0">Zhè</span><span style="color:#a78bfa">lǐ</span>
> *"A is here" — 這裡 means "here"*

4. <span style="color:#a78bfa">wǒ</span> <span style="color:#b0b0b0">Zài</span> <span style="color:#b0b0b0">Zhè</span><span style="color:#a78bfa">lǐ</span>. — I am here.

5. <span style="color:#ff6b35">TĀ</span> <span style="color:#b0b0b0">Zài</span> <span style="color:#b0b0b0">Nà</span><span style="color:#a78bfa">lǐ</span>. — He is there.

> **💡 Pattern:** <span style="color:#b0b0b0">Qù</span> / <span style="color:#6edcb8">láI</span>
> *"go" / "come" — movement verbs*

6. <span style="color:#a78bfa">nǐ</span> <span style="color:#b0b0b0">Qù</span> <span style="color:#a78bfa">nǎ</span>? — Where are you going?

7. <span style="color:#6edcb8">láI</span> <span style="color:#b0b0b0">Zhè</span><span style="color:#a78bfa">lǐ</span>! — Come here!
